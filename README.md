# ぶくろく 🐾

愛犬・愛猫のお世話を家族で記録できる、シンプルなペット健康管理アプリです。

## できること

- **日々のお世話記録**：ごはん・お水・おしっこ・うんち・吐いた・散歩・気になる様子・健康チェックをワンタップで記録
- **体重管理**：体重の推移をグラフで確認
- **通院・投薬・トリミング**の記録
- **予防接種・投薬スケジュール**（狂犬病・混合ワクチン、フィラリア・ノミ予防など）の管理
- **きろく（履歴）**：過去の記録を一覧で確認・編集
- 家族みんなで同じ記録を共有

## 画面構成

- 🏠 ホーム：ペットの基本情報とお世話の記録
- 📖 きろく：記録の履歴一覧
- ⚖️ 体重：体重グラフと記録一覧
- ⚙️ 設定：ペット情報の編集など

## 使い方

`index.html` をブラウザで開くだけで利用できます（Firebaseと連携してデータを保存します）。
