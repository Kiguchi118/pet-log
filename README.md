# ぶくろく（無料・外部運用版）セットアップ手順

**GitHub Pages（無料ホスティング）＋ Firebase Firestore（無料データベース）** だけで動きます。
クレジットカード登録は不要です。

このバージョンから、**パスワードでログインする仕組み**が入りました。一度ログインすれば、
同じ端末・ブラウザでは次回以降も自動でログインされたままになります（毎回の入力は不要です）。

---

## アップロードするファイル一式

```
index.html
manifest.json
icon-192.png
icon-512.png
icon-512-maskable.png
icon-180.png
favicon-32.png
```

（すべて同じ階層＝リポジトリ直下でOKです）

---

## 1. Firebaseプロジェクトを作る

すでにFirebaseプロジェクトを作成済みの場合は、この手順はスキップして「2. ログイン用のユーザーを作る」に進んでください。

1. https://console.firebase.google.com/ を開く（Googleアカウントでログイン）
2. 「プロジェクトを作成」→ 名前を入力（例：bukuroku）→ Googleアナリティクスは「オフ」でOK →「プロジェクトを作成」
3. プロジェクト画面で `</>`（Webアプリ）のアイコンをクリック→ニックネームを入力→「アプリを登録」
4. 表示される `firebaseConfig` の6つの値をコピーし、`index.html` 上部の該当箇所に貼り付ける

```js
const firebaseConfig = {
  apiKey: "ここにAPIキーを貼り付け",
  authDomain: "ここにauthDomainを貼り付け",
  projectId: "ここにprojectIdを貼り付け",
  storageBucket: "ここにstorageBucketを貼り付け",
  messagingSenderId: "ここにmessagingSenderIdを貼り付け",
  appId: "ここにappIdを貼り付け"
};
```

（`FAMILY_ID` はそのままでOKです）

---

## 2. ログイン用のユーザーを作る（今回の重要ポイント）

以前の「匿名ログイン」から「パスワードでログイン」する方式に変わりました。

1. Firebaseコンソール →「Authentication」→「Sign-in method」タブ
2. もし「匿名」が有効になっていたら、オフにしてOKです（もう使いません）
3. 「新しいプロバイダを追加」→「メール/パスワード」→ 有効にする → 保存
4. 「Users」タブ →「ユーザーを追加」
5. メールアドレス欄に、**`index.html` に書かれている `LOGIN_EMAIL` の値と完全に同じ文字列**を入力
   - `index.html` を開くと `const LOGIN_EMAIL = "family@bukuroku-app.com";` と書かれています
   - この通り一字一句コピーして入力してください（変更しても構いませんが、その場合は `index.html` 側の値も同じように書き換えてください）
6. パスワード欄に、あなたと配偶者で使う**ログインパスワード**を決めて入力 →「ユーザーを追加」

これで完了です。今後アプリを開いたとき、ここで決めたパスワードを入力すればログインできます。

---

## 3. Firestore Database を作る

（すでに作成済みならスキップ）

「Firestore Database」→「データベースを作成」→ ロケーションは `asia-northeast1（東京）` → 「本番環境モードで開始」

## 4. セキュリティルールを設定する

「ルール」タブで以下に置き換えて「公開」

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

これで「ログインした人だけ読み書きできる」状態になります。

---

## 5. GitHubにアップロードする

1. リポジトリを開く（既存のものでOK）
2. `index.html`・`manifest.json` を、今回の新しいものに差し替える（鉛筆マークで編集→中身を全部置き換え→Commit、が確実です）
3. アイコン画像（`icon-192.png` など）は前回アップロード済みならそのままで大丈夫です

## 6. GitHub Pagesの反映を待つ

1〜2分待ってから、発行済みのURLを開き直してください。

## 7. 動作確認

1. URLを開く → パスワード入力画面が出る
2. Step2で決めたパスワードを入力 →「ログイン」
3. 初回だけペット情報（名前・顔写真など）を登録
4. 一度ブラウザを閉じて開き直しても、ログイン画面が出ずにそのままホーム画面が開けばOK

---

## 今回追加された機能

- **ログイン機能**：パスワードを知っている人だけがアプリを開けます。一度ログインすれば自動的にログイン状態が続きます（ブラウザのデータを消したり、設定画面から「ログアウト」を押すと再度パスワードが必要になります）。
- **記録の編集・削除**：「きろく」タブや日記の一覧で、記録をタップすると内容を編集したり削除したりできます。
- **ペットの顔写真**：設定タブから顔写真を登録・変更できます。ホーム画面のアイコンにも反映されます。
- **日記に日付・記録者を表示**：一覧に日付と記録した人の名前が表示されるようになりました。
- **体重画面の不具合を修正**：ずっと読み込み中になっていた原因を直し、体重・前回や1ヶ月前との比較・最小最大なども見やすく表示されるようにしました。
- **人間換算の年齢（目安）**：ホーム画面にペットの年齢を人間換算した、おおよその目安を表示します（正確な数値ではありません）。
- **「今日まだのお世話」カードを削除**しました。
- 犬を選んでいる場合はホーム画面に「子犬期／成犬期／シニア期」、猫の場合は「子猫期／成猫期／シニア期」など、選んだ種類に応じた表記になりました。
- ペットの名前のフォントを、他の文字と統一した丸ゴシック系の可愛らしい書体（Zen Maru Gothic）に変更しました。
- ヘッダーの「ぶくろく」の文字表示をなくし、肉球アイコンのみのシンプルな見た目にしました（ブラウザのタブ名やホーム画面のアプリ名としては引き続き「ぶくろく」が使われます）。
- ホーム画面に「健康・予防の管理」セクションを追加し、ワクチン（狂犬病・混合）と予防のお薬（フィラリア・ノミ・マダニ）をグループ表示できるようにしました。記録すると次回の目安が自動で「次回の予定」に表示されます。

## 補足

- **無料枠**：Firestoreの無料枠（1日あたり読み取り5万回・書き込み2万回、保存容量1GiB）は、お二人での利用なら十分すぎるほど余裕があります。
- **バックアップ**：Firebaseコンソールの「Firestore Database」からいつでもデータを確認できます。
- **今後の改良**：`index.html` は1枚のファイルで完結しています。GitHub上で直接編集→Commitするだけで、1〜2分後にサイトに反映されます。
